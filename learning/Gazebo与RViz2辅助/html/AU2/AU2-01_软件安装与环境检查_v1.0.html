AU2 软件安装与环境检查¶

适用环境：Ubuntu 22.04、ROS 2 Humble、Gazebo Classic、RViz2
对应计划：AU2

1 本单元定位¶

本项目明确使用Gazebo Classic和gazebo_ros，不是新版Gazebo Sim。安装时必须先确认项目基线，避免混用两套命令、插件和文件格式。

2 学习目标¶

  • 识别Ubuntu、ROS 2和Gazebo版本；
  • 检查Gazebo、RViz2、Nav2与项目依赖；
  • 验证工作区构建、环境加载和基础启动；
  • 能区分“软件未安装”和“项目环境未加载”。

3 版本边界¶

课程基线为Ubuntu 22.04和ROS 2 Humble。项目的Launch文件包含gazebo_ros，机器人使用libgazebo_ros_diff_drive.so、libgazebo_ros_camera.so等Gazebo Classic插件。因此教材操作以Gazebo Classic为准。

Gazebo Classic已经结束上游生命周期，但现有项目仍依赖它。课程目标是掌握并维护当前项目，不把新版Gazebo Sim的gz sim命令和插件名称混入本项目。后续迁移应另立任务。

4 安装与检查¶

先检查系统：

lsb_release -a
printenv ROS_DISTRO

检查命令与软件包：

which gazebo
which rviz2
ros2 pkg prefix gazebo_ros
ros2 pkg prefix rviz2
ros2 pkg prefix nav2_bringup

需要安装时，在Ubuntu 22.04和ROS 2 Humble的软件源已经正确配置的前提下使用：

sudo apt update
sudo apt install ros-humble-gazebo-ros-pkgs ros-humble-rviz2 ros-humble-navigation2 ros-humble-nav2-bringup

不要把密码、私钥或远程凭据写入学习证据。

5 项目构建与环境加载¶

cd /home/ubuntu/ai_robot_ws
./scripts/build.sh
source install/setup.bash

检查项目包：

ros2 pkg prefix ai_robot_description
ros2 pkg prefix ai_robot_sim

检查Launch参数：

ros2 launch ai_robot_sim sim_bringup.launch.py --show-args

当前项目应至少显示gui、world和require_scan参数。

6 启动验证¶

Gazebo GUI验证：

ros2 launch ai_robot_sim sim_bringup.launch.py gui:=true

RViz2验证：

rviz2

ROS图验证：

ros2 topic list
ros2 topic echo /clock --once

7 正常现象¶

  • 构建脚本无失败软件包；
  • Gazebo GUI能够打开并生成ai_robot；
  • RViz2能够独立启动；
  • /clock存在并持续更新；
  • ai_robot_sim和ai_robot_description能被ROS 2找到。

8 常见问题与排查¶

8.1 找不到软件包¶

先执行：

source /opt/ros/humble/setup.bash
source /home/ubuntu/ai_robot_ws/install/setup.bash

仍找不到时再判断是否未构建或未安装。

8.2 Gazebo有服务器但无窗口¶

检查是否使用gui:=true。后台自动测试通常只启动服务器，不弹出客户端。

8.3 插件加载失败¶

确认安装gazebo_ros_pkgs，并检查Xacro中的插件名称是否属于Gazebo Classic。

8.4 启动后残留进程¶

先在原终端用Ctrl+C正常结束，再检查是否仍有Gazebo或ROS节点。不要用强制清理代替正常关闭流程。

9 独立人工练习¶

不看步骤完成：系统版本检查、工作区构建、环境加载、Gazebo GUI启动、RViz2启动和/clock检查。

10 理解检查¶

  1. 为什么本课程不能直接使用新版Gazebo插件名称？
  2. source /opt/ros/humble/setup.bash和source install/setup.bash分别加载什么？
  3. Gazebo后台运行时为什么可能没有窗口？
  4. 软件已安装但ros2 pkg prefix失败，优先检查什么？

11 操作技能检查与证据¶

保存版本信息、构建摘要、Gazebo与RViz2启动截图、/clock检查结果。全部可复现且无未解释错误，即可标记AU2完成。

# AU9 GUI默认入口技术验证记录

时间：2026-09-28 18:01 PDT
范围：AU9导航工具测试的Gazebo/RViz2默认可见入口
实体设备操作授权：未授权，本轮仅执行Gazebo仿真

## 1. 目标

直接执行以下原始命令时，默认显示Gazebo和RViz2测试界面：

```bash
launch_test tests/integration/test_au9_navigation_tools.launch.py
```

无图形界面的自动化环境可显式使用：

```bash
AU9_TEST_GUI=false launch_test tests/integration/test_au9_navigation_tools.launch.py
```

## 2. 实现

- `tests/integration/test_au9_navigation_tools.launch.py`默认向`apartment_nav2_bringup.launch.py`传递`gui:=true`和`rviz:=true`。
- 环境变量`AU9_TEST_GUI`接受`0/false/no/off`关闭两个GUI，其他值或未设置时默认显示。
- GUI开关不改变航点、Action、安全速度链、断言或超时。

## 3. 测试结果

- 使用不带环境变量前缀的原始命令执行。
- `gzclient`与`rviz2`均自动启动；RViz2加载144×170静态地图及60×60局部代价地图。
- 多航点、运动中取消、取消后停车和返回起点全部完成。
- 退出码：`0`。
- 结果：`Ran 1 test in 56.603s`，`OK`。
- 日志：`/home/ubuntu/.ros/log/2026-09-28-17-59-16-285191-ubuntu-128148/launch.log`。
- `git diff --check`：通过。

## 4. 观察与风险

- 返回起点期间出现一次`Failed to make progress`，Nav2自动恢复后成功到达。
- GUI负载下出现少量RViz2旧时间戳丢帧、行为树频率和控制循环频率警告，未影响最终结果。
- RViz2在测试收尾接收SIGINT后退出码为`-11`；运行期显示正常，但关闭异常仍为待定位风险。

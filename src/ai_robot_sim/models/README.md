# 温室正式模型资源（FreeCAD v3.4）

正式World：`../worlds/greenhouse_env.world`。运行：`bash scripts/view_greenhouse_env.sh`。该版本由用户指定，将已人工检查的FreeCAD v3.4候选World提升为正式World；此次采用整套候选环境，不与旧World的单体构件混合。

运行时网格资源位于`greenhouse_cad_v34/meshes/`，World通过`model://greenhouse_cad_v34/meshes/`引用，`setup.py`会递归安装该目录。目录包含693个本地DAE/STL文件；World有1,645条网格URI引用，均不依赖临时目录。现行工程规范的权威文件位于`plan/温室环境建模规范_v1.6.md`；`docs/greenhouse_cad_v34/`保存FreeCAD源文件、CAD清单、审查报告、生成报告及规范/World参考副本。

正式场景包含1,590个World link、60个碰撞对象；包括60条种植行、58组双轨和58组整体灰色轨道支撑。温室建筑梁柱檩条及连接件均为纯白，轨道支撑钢板与支腿统一为中灰钢材质，轨道为黄色钢管外观；地坪、通道、黄线、外部浅棕地面、天空和玻璃按FreeCAD v3.4候选配置。所有visual关闭投影阴影。该World不含采摘机实例，也不单独设置物理步长。

番茄根部的栽培入口使用共享`TomatoModuleMultiMaterial.dae`中的浅棕色渐缩视觉柱：每个2 m网格单元内4处根点各一个，底部略埋入Z=0.95 m土面，柱体上端与现有茎秆重叠。由`scripts/build_tomato_root_collars.py`可重复生成；不改变World link、visual实例或collision数量。定向pytest、DAE/SDF解析及正式Gazebo目视复核均已通过。每个共享植株网格新增640个三角面（原有22,540面，增加2.84%）；正式World复用该DAE 900次，场景共增加576,000个三角面。场景FPS前后对照尚未测试。

包内静态契约：`src/ai_robot_sim/test/test_greenhouse_env.py`。候选原有验证结论和规范镜像保存在`docs/greenhouse_cad_v34/`；当前正式World已经由用户指定，但整场性能、轮轨动态接触和全部系统验收仍未完成。旧模型目录保留在包内，正式温室World不再引用它们。

Gazebo坐标使用FreeCAD设计坐标平移`(-31.5, -22.075, 0)`，温室中心对齐原点。

## 采摘机四轮底盘正式模型

模型目录：`picker_chassis_4wd/`；Gazebo模型名：`picker_chassis_4wd`。该模型由隔离四轮候选正式整理而来，轴距0.900 m、左右轮中心距0.550 m，四个驱动轮由差速插件按前后两轴共两组控制；驱动轮名义直径0.248 m。动力学参数和轮组布局保持本次U形入口通过测试的配置。模型自带的差速控制命名空间为`/picker_test`，速度命令话题为`/picker_test/cmd_vel`。

传感器配置依据：`docs/四驱采摘机底盘_黄色顶板_v0.7.zip`内的《四驱采摘机底盘_模型及传感器说明_v1.0.md》（2026-11-10）。雷达选型为思岚 SLAMTEC RPLIDAR S2 标准串口版：360°二维 dToF，典型10 Hz、32,000次/秒，测距范围为90%反射率下0.05–30 m、10%反射率下0.05–10 m，角度分辨率0.1125°、测距精度±30 mm，UART 1 Mbit/s、5 V、IP65、工作温度−10至50℃。名义扫描面位于底盘坐标`(0, 0, 0.660) m`。

前置双目相机选型为 RealSense D456 USB：双目基线95 mm，外形124×29×26 mm，理想工作距离0.6–6 m，最大分辨率下最近测深约0.52 m，深度视场角87°×58°；深度最高1280×720、最高90 fps，彩色最高1280×800、30 fps，另含IMU、USB 3/USB-C、IP65及红外纹理投射器。底盘坐标中的俯仰轴中心为`(0.650, 0, 0.380) m`，支架审查范围为左右各45°、向下俯仰0–20°，默认向下10°；转动后的坐标换算需使用当时支架角度。

`model.sdf`现已按上述位置加入黄色顶板、中央服务器箱、雷达支座与外壳、相机转台/支架及双镜头的仅视觉示意；这些几何不增加碰撞体、不改变底盘质量或驱动。服务器箱外形为400×300×250 mm，SDF以240 mm箱身和10 mm顶盖组合表示，四只安装脚高10 mm，箱顶为底盘坐标Z=560 mm。雷达外形尺寸在源说明中未给出，因此为便于视图识别采用示意包络。Gazebo雷达/相机传感器插件和ROS 2数据话题仍未接入；相机支架当前固定显示为默认向下10°，旋转范围未做动态关节。实际设备尾缀、扫描面、安装孔、相机光学坐标和真实输出模式仍需按交付设备核对。

测试依据：`tests/evidence/picker_gazebo/2026-11-10-四轮双轴驱动U形复盘/`。隔离仿真在ODE步长0.2 ms时完成U形端头过渡，目标位姿达到；这证明该模型配置在该测试World/起始条件下通过，不等同于正式集成验收或真实车辆验收。原六轮ZIP资料及四轮候选完整封存继续保存在测试证据目录，不被覆盖。模型资源由`setup.py`的递归规则安装。

采摘机模型仍保存在`picker_chassis_4wd/`供独立测试；当前正式温室World不加载该模型。温室新World未设置ODE最大步长，后续若在该场景加入采摘机或开展动力学测试，再根据测试目标配置仿真参数。

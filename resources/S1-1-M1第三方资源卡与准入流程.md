# S1-1-M1 第三方资源卡与准入流程

版本：v1.0
阶段：阶段 1，S1-1-M1 资源、接口与测试基线

## 资源卡模板

```markdown
# 资源卡：{资源名称}

- 来源：{官方仓库或发布页}
- 许可证：{SPDX标识或许可证名称}
- 维护状态：{维护中/冻结/未知}
- 锁定版本：{版本、提交或发行包版本}
- ROS 2与系统兼容性：{ROS 2 Humble、Ubuntu 22.04验证结果}
- 安装方式与依赖：{apt、源码、容器或其他}
- 接口：{Topic、Service、Action、消息、QoS、Frame、参数}
- 资源需求：{CPU、GPU、内存、网络、设备}
- 仿真实现：{实现方式或不适用}
- 实体实现与替代方案：{实现方式、风险和回退}
- 最小验证：{命令、结果、日期和证据路径}
- 已知问题：{问题、影响和规避方式}
- 准入结论：{候选/准入/拒绝}
```

## 准入流程

1. 记录来源、许可证、维护状态和锁定版本。
2. 在Ubuntu 22.04与ROS 2 Humble环境完成可重复安装或构建。
3. 启动最小样例，验证启动、停止和重启行为。
4. 记录并检查Topic、Service、Action、消息、QoS、Frame和参数。
5. 执行至少一项自动接口或节点测试，并保存证据路径。
6. 检查设备断开、输入异常或数据超时不会绕过安全边界。
7. 评审仿真/实体替换关系、资源需求和回退方案后，记录准入结论。

## 准入判定

只有同时满足以下条件的资源可以标记为“准入”：许可证可接受、版本可复现、最小样例可稳定运行、接口可适配、关键输出可自动检查、异常行为不绕过安全控制。

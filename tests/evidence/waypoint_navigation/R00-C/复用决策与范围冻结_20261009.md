# R00-C复用决策与范围冻结

日期：2026-10-09 PDT。审查依据：原需求规范v1.1、项目计划v1.3及R00-A/B证据；当前冻结有效版本为需求规范v1.2、项目计划v1.4。状态：TR-C01–05技术验收通过，路线/架构/接口/实施范围已冻结；应用尚未实现，U01及后续功能未验收。

## 任务边界

当前唯一目标R00-C：以已测资源确定复用路线和实际缺口，形成逐需求/逐单元映射，按实际方案复验最小闭环后版本化冻结。本轮完成分析、文档及定向仿真复验；不实现U02–U10完整应用，不执行U01，不改变固定需求，不重写Nav2内部算法，不覆盖已有工程改动，不操作实体。

R00-B按既定评估条款已通过并远端归档；候选失败不自动撤销资源评估验收。此前“候选必须全部满足需求才能进入R00-C”的门槛不适用。R00-C可开展选型论证，但风险不能隐藏，方案冻结不等于软件功能验收。

## 三种路线比较与选定结论

| 路线 | 实测能力与代价 | 决定 |
|---|---|---|
| 直接采用完整现成应用 | 未找到满足全部固定需求的已验证组合；现有Plugin为编辑器，不是任务应用 | 不采用，保留缺口，不降低需求 |
| A：官方异步Action薄适配 | 两条Nav2 Action原语、真实GUI导航成功、取消与故障记录；可分别管理规划/执行句柄 | 选定生产集成路线，复用底层服务器和既有输入 |
| B：Commander隔离封装 | 官方库可运行；原生服务器等待无总截止时间，共享句柄，规划中取消/响应前端未闭环 | 不选生产入口，保留比较证据，不引入生产运行依赖 |
| 备用mapoi管理＋替换后端 | 未运行，接口/连续导航差距及新增依赖成本未证实 | 不选，不作为已验证依赖；不为数量新增实测 |
| 自研规划器/控制器或新GUI | 没有充分证据表明现成Nav2算法必须重写；现有RViz能输入 | 不实施 |

复用：ROS2 Humble、已安装Nav2 1.1.20的ComputePathThroughPoses和FollowPath、现有Waypoint Plugin编辑/Publish、TF/rclpy及现有安全速度链。来源/包版本/许可证与SHA256沿用R00-A固定元数据及R00-B本机快照；不把上游分支SHA当作已安装二进制SHA。客户端只调用API，不复制上游控制算法代码。新包为src/waypoint_navigation，Python异步薄适配，未创建该包。

## 接口冻结

为消除规范“包名称空间”和手册“节点私有服务前缀”的歧义，拟用统一应用名称空间/waypoint_navigation。节点名waypoint_path_navigator，服务用相对名plan/execute/cancel/save/load，而非~/plan等私有名。

| 接口 | 冻结名称 | 类型/语义 |
|---|---|---|
| 航点输入 | /waypoint_path | nav_msgs/Path，兼容现有插件，仅配置 |
| 规划预览 | /waypoint_navigation/prepared_path | nav_msgs/Path，与航点输入分离 |
| 加载航点显示 | /waypoint_navigation/loaded_waypoints | nav_msgs/Path，不回发输入 |
| 服务 | /waypoint_navigation/plan、execute、cancel、save、load | std_srvs/Trigger；plan/execute/cancel响应表示请求接受，不是任务完成 |
| 状态 | /waypoint_navigation/status | std_msgs/String，带schema_version的JSON |
| 后端 | /compute_path_through_poses、/follow_path | Nav2 Action，参数化适配名称空间 |

应用名称空间可配置；输入及后端Action默认明确为现有绝对名称，不随应用名称空间误指向不存在服务器。U02验证名称空间/重映射。规范v1.2、计划v1.4、手册v1.2已同步升版并保留历史；接口已写入有效规范，新包仍须U02以后实现。

## 已知问题的处理分工与冻结边界

- 时间基准：执行路径Pose使用最新TF，原规划时间独立保留作年龄判断。不得以清零全部时间或修改frame_id冒充有效转换；U06/U07/U08复验。原型开关和三会话证据可作为选定适配依据，不是完整年龄门控。
- 控制器：仍复用官方Nav2控制器，不自研。RPP评估profile只在开放场景通过，反向转向仍失败，不能把该profile认定为通用生产默认。U01承担正式环境/控制参数核对与基础故障处理；若需要变更复用组件或接口，返回R00-C更新方案，不暗中改变选型。
- 反向和绕墙：明确留作基础导航/控制参数风险；不得取消U08转弯/绕墙或终点朝向验收。任务结果必须独立检查map轨迹和终点。要扩大控制器对比或新增组件时先列出定向计划，不能全工作区试错。
- B无界等待：通过不选Commander入口避免引入该生产依赖；A自行有界发现/规划等待仍需U06/U09测试。
- GUI输入工具：真实RViz输入已有成功证据，自动化焦点保护受阻也有记录；生产输入插件不因测试工具失败被替换。后续GUI预览/加载须真实验收，未测不标通过。

这些风险可以在R00-C论证中明确分配，不能被“R00-B通过”掩盖，也不能把R00-C错误升级为所有后续功能已验收。最终文件须明确组件、接口、缺口、责任单元及变更回退条件。

## 原型闭环和证据解释

本机固定版本：rclpy 3.3.21；Nav2 msgs/planner/controller/RPP 1.1.20，完整Debian版本见运行证据package_versions.txt。API仍为Humble字段，不硬编码rolling错误字段。相关包声明和关键文件SHA见固定组件元数据_20261009.json；NavFn包声明Apache-2.0和BSD-3-Clause，不能将整个依赖树概括为同一个许可证。现有Waypoint 1.0.0的package.xml及README声明Apache-2.0，源码为项目既有包；固定项目修复提交be1b7c3，未新复制算法源码。交付时仍按文件保留来源和许可证，不凭声明覆盖第三方文件。

成功用例：运行证据_20261009/closed_loop_buttons_fixed。实际收到一份真实RViz Path，含两点(2.200001,3.993754)、(2.600001,3.993752)。空单Pose参考系继承父Path；输入时本地Action数量0；规划只创建1个ComputePathThroughPoses目标，返回30项路径并发布评估预览；执行阶段才创建1个FollowPath目标。实际位移0.656256 m，按序航点最小距离0.007636/0.142647 m；终点位置0.142647 m、朝向0.013618 rad，Action SUCCEEDED，末端速度零。

预览在隔离评估话题/r00b/a/prepared_path发布；正式应用的/waypoint_navigation/prepared_path及五个服务尚未实现，U02/U07必须验证。测试驱动显式分开API调用阶段，不表示最终服务/任务协调器已经交付。RViz截图仅辅助，不能独自证明实际经过或完整规划预览显示。

运动取消用例：运行证据_20261009/cancel。真实记录运动，取消回复return_code=0、1个目标进入取消，执行结果CANCELED(5)，后续速度观测为零。停止/启动收尾退出0、无仿真/候选进程、11345释放。trial profile从原true/0.25m/0.25rad改为false/0.15m/0.20rad，试验后全部回读恢复；外部试验判定仍0.25m/0.25rad，不作U01指标冻结。

失败过程完整保留：两个布局检查拒绝（桌面1024x768及最大化回弹）、辅助缺yaml导入、旧Publish按钮行点击导致观察超时；这些用例没有创建Action目标，不认定导航失败。缺导入已补回，Clear/Publish行新增显式辅助参数；成功实测验证修复。为试验临时使用1920x1080、RViz1500x900，解最大化后按截图241像素按钮行操作；结束后恢复1024x768。辅助布局不是生产应用限制。

## 可复现最小原型命令

先source scripts/au9_sim_environment.sh；启动现有scripts/start_au9_manual_nav2.sh，等待两组Active。真实GUI辅助需要已核对的窗口/按钮行，并保持焦点与指针保护；当前实测为1500x900、按钮行241，其他布局须先核对，不盲目点击。

```bash
/usr/bin/python3 tests/helpers/r00b_goal_checker_profile.py --output log/R00C_reproduce/profile_apply.json
timeout 150s /usr/bin/python3 tests/helpers/r00b_candidate_probe.py --route A --scenario open --gui --gui-button-y 241 --latest-path-transforms --output log/R00C_reproduce/closed_loop
timeout 150s /usr/bin/python3 tests/helpers/r00b_candidate_probe.py --route A --scenario cancel --latest-path-transforms --output log/R00C_reproduce/cancel
/usr/bin/python3 tests/helpers/r00b_goal_checker_profile.py --restore log/R00C_reproduce/profile_apply.json --output log/R00C_reproduce/profile_restore.json
bash scripts/stop_au9_manual_nav2.sh
```

逐条确认结果；应用参数失败不继续，任何活动目标未知/超时要独立停止，不仅杀客户端。GUI保护受阻保留为受阻，不改写为通过。以上只是原型，未来正式用户命令以手册v1.2为实现目标，未开发包不能运行。

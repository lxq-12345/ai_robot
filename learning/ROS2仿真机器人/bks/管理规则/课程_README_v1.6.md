# ROS 2仿真机器人课程

版本：v1.6

## 1. 课程定位

本课程基于已经完成的`S1-1-M0`至`S1-1-M6`工程成果，严格按照开发单元进度组织学习。M是一级学习骨架，L是M下的学习子单元；课程不建立与开发计划平行的PU主编号，也不改变`S1-1-G1`验收要求。

## 5. 进度处理

原PU1-01至PU1-05的内容已分别归入M0和M1。此前完成的示例包、接口包和描述包测试作为M1-L1的程序包识别与测试入口证据保留，但不代表M2至M6学习完成。

原PU2“ROS 2工程运行与系统观察”没有形成正式教材，因此M0-L2仍是当前缺口。课程恢复严格顺序后，先补齐M0-L2和M0-L3测试子单元，再回到M1-L1继续`ai_robot_sim`包入口识别。

每个M最后一个L是必修测试与证据子单元。功能学习、程序包测试和M工程验收分别记录；没有完成规定测试阅读、执行、断言解释和证据时，M学习不能结项。

测试的物理位置和使用规则统一见项目根目录`tests/README.md`。课程索引按M引用测试，但不复制测试文件，也不以M建立平行测试目录。

## 6. 阅读与生成

维护教材时编辑`source/`中的Markdown，再使用：

```bash
/usr/bin/python3 scripts/render_learning_html.py \
  learning/ROS2仿真机器人/source/S1-1-M1/S1-1-M1-L1-01_程序包与工程资源_v1.2.md \
  learning/ROS2仿真机器人/html/S1-1-M1/S1-1-M1-L1-01_程序包与工程资源_v1.2.html
```

生成后检查链接、图片、目录、桌面与移动排版，并确认HTML与Markdown版本一致。

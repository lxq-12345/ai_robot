# ROS 2仿真机器人课程

版本：v1.8

## 1. 课程定位

本课程基于已经完成的`S1-1-M0`至`S1-1-M6`工程成果，严格按照`plan/ROS2仿真机器人学习计划_v1.8.md`组织。M是开发单元和一级学习骨架，L是M下的学习子单元；教材、练习、测试和证据均按M/L追溯，但测试文件仍按`tests/README.md`规定的代码责任存放。

教材技术形成不等于学员学习通过。每章必须经过教材讲解、理解检查、学员亲自练习和证据记录，才能形成L学习结论；每个M最后的测试与证据L未通过时，该M学习不能结项。

## 5. 计划与教材同步规则

学习计划变更后，必须逐项核对20个L的Markdown、HTML、程序包、测试路径、人工练习和证据要求。新增L没有教材时，不得把该L切换为正式学习目标；测试建议只能作为教材准备材料。

本次v1.8同步修复了旧PU迁移残留、五章总序号、M1-L2版本不一致以及M1-L3跳过M1-L4的问题。历史版本保存在`bks/`，不再作为当前入口。

## 6. 阅读与生成

维护教材时编辑`source/`中的Markdown，再使用：

```bash
/usr/bin/python3 scripts/render_learning_html.py <source.md> <target.html>
```

生成后检查Markdown/HTML版本、链接、目录、代码块和桌面/移动排版。学员学习顺序始终是：教材讲解→理解检查→亲自练习与测试→证据→L结论。

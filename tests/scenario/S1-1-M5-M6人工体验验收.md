# S1-1-M5/M6人工体验验收

本测试仅操作Gazebo仿真机器人，不构成实体机器人上电或运动授权。

## 前置条件

- 当前提交已执行`./scripts/test.sh`且退出码为0，M5/M6契约、集成和系统自动测试均通过；
- 操作者可同时观察终端与Gazebo窗口，并了解`Ctrl+C`停止方法；
- 不直接发布`/cmd_vel`或`/cmd_vel_raw`，不修改速度、安全和超时参数。

## 启动

```bash
./scripts/build.sh
./scripts/start_m5_m6_manual_experience.sh
```

启动后保持终端和Gazebo窗口同时可见，根据终端提示按Enter推进。

## S1-1-M5观察项

- 可达目标：机器人在Gazebo中运动，终端持续显示剩余距离，最终返回`SUCCEEDED`。
- 导航取消：机器人运动后由操作人按Enter取消，返回`CANCELED`并在2秒内停车。
- 安全链：控制台不得直接发布`/cmd_vel`或`/cmd_vel_raw`，运动由Nav2经`cmd_vel_guard`完成。

## S1-1-M6观察项

- 结构化任务：反馈依次出现`VALIDATING`、`NAVIGATING`和`PERCEIVING`。
- 到点感知：结果为`SUCCEEDED`，雷达最小距离大于0，图像宽度和高度大于0。
- 幂等重放：相同`task_id`返回`replayed=True`，机器人不再次运动。
- 安全停车：操作人按Enter发布仿真`/safety_stop`，结果为`SAFETY_TRIGGERED`并在2秒内停车。

## 通过标准

- 控制台最终汇总中的全部项目均为`PASS`。
- Gazebo中机器人运动、取消、重放不运动和安全停车现象与终端结果一致。
- 测试退出后Gazebo、Nav2和任务管理器正常关闭，无残留进程。
- 人工填写测试时间、观察人、结果和异常说明，并写入当前里程碑备忘。

## 停止与恢复

任何现象与预期不符时，先按场景提示触发仿真安全停车，再在启动终端按`Ctrl+C`。确认Gazebo、Nav2、任务管理器和速度守卫均已退出；保留失败日志，不跳过失败项继续形成通过结论。修复后重新执行自动前置测试和完整人工场景。

## 证据

使用`tests/evidence/test_evidence_template.md`记录提交号、操作者、自动测试前置结果、各观察项、截图或录屏、日志路径和最终结论。结论只填写“通过、未通过、未执行”；仅有自动测试结果时，本人工场景必须记录为“未执行”。

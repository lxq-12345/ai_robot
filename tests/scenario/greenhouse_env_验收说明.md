# 温室静态环境用户验收

关联：阶段1仿真AU9-03，非Gate或轮轨动态验收。

前置：开发自测证据见`tests/evidence/greenhouse_env/开发自测.md`。不关闭已有房屋会话；11365端口须空闲。

启动：项目根目录执行`bash scripts/view_greenhouse_env.sh`。仅加载静态温室，无机器人、导航及运动控制。

1. 全景检查：两段种植区、中间3 m通道、外围矮墙、南侧入口；60条种植行、58组双轨。
2. 外观检查：干燥棕土、中浅灰通道/基座、深棕种植面、绿色番茄行及少量红色果实、黄色涂漆轨道。
3. 近景检查：基座与通道等高；轨道高于通道0.05 m，两侧U形端头朝通道伸入；最外端不穿墙。
4. 菜单开启碰撞显示，检查地坪、墙体、通道、番茄行、基座、钢管；种植面及番茄点缀无独立碰撞。
5. 保存全景、端头、碰撞显示截图，记录通过/未通过。外观由操作者确认，开发者截图不代替用户验收。

停止：窗口关闭后在启动终端Ctrl+C，确认本次Gazebo退出；不得使用广泛pkill干扰其他会话。

禁止：实体操作、加载运动插件、把静态结果称为轮轨动态通过。实际轮型、速度及偏差条件确定后另立轮轨动态测试。
